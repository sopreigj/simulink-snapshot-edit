# 解释：为什么"模型=唯一真相"，快照是它的代码影子

这篇讲设计动机与取舍，不教操作。想知道"怎么做"去 [how-tos/](../how-tos/)。

## 要解决的问题

从零生成模型的 build 脚本每次**全量重建**——手工拖动、相对布局这些排版成果全丢。每次"改一个参数"都要重跑整个生成脚本，然后人再排一次版。

本工具把工作流倒过来：**模型 → M**。模型（人 GUI 维护、含全部排版成果）是**唯一真相**；M 快照是它的**代码影子**。之后小改只改 M 里几行再重跑，其他块与相对位置逐字节不变。

"唯一真相"的意思是明确的：
- 两边不一致时，**以模型为准**（`snp_pull` 把模型变更合并回快照）；
- 快照的价值不在"它是另一份模型"，而在它是**可读、可逐字节验证、可跨版本移植**的载体；
- 人永远在 GUI 里工作，不需要读代码；agent 永远在代码里工作，不需要操作 GUI。双方通过同一份文本协作。

## 三级编辑阶梯：为什么不是一个工具

（约定：① XML 原地编辑+重打包；② XML 经解析后回灌 M；③ agent 读筛选后内容改 M。）

关键观察：**两条路线的能力是互补的，不是替代的**——

XML 路线（①）：
- 改 XML **不需要块型的库路径**（`add_block` 才需要）；
- 不需要重建模型——未列白的参数、Stateflow、Simscape 物理连接**字节级保留**；
- 代价：产物是"改过的 .slx"，不是"能重建的 M"。

M 路线（③）：
- 产物可重建、可逐字节验证、**跨版本可移植**（R2023b 快照在 R2026a 上重建逐字节一致，实测）；
- 代价：需要块型→库路径表；需要结构化导出每种特殊内容（chart、物理网络）。

级②（`snp_sync_m`）是桥：XML 做编辑，`info.mops` 自动回灌 M——兼得①的速度和③的可验证性。**M 定为贯穿三级的兜底真相**：无论从哪级动手，最终 M 要与模型一致。

## 为什么 M 快照刻意保留几何（Position / Points）

这是最容易误解的一点，值得单独讲：

- **XML 路线剔除几何**：块位置与走线是**展示属性**，Simulink 自动排列负责；实测布局类参数约占 XML 参数项的 59%，剔除后体积约减半。人机协作不需要agent 写几何。
- **但 M 快照保留 `Position` 和 `Points`**：因为"运行一次就完全重建"需要 **逐字节可重建**——示例资产 5 份快照实测全部含 `add_block(...,'Position',...)`与 `add_line(...'Points',...)`。这不是"编辑坐标"，是重建的必需。

所以第三级路线的"去坐标视图"是**读视图**（`snp_view_nogeom` 产出），基于"忽略几何行"，而不是"快照无坐标"——M 本身永远带几何，不要为了可读性删掉它。

## 库路径知识的归属（为什么表只有一份）

库路径是 **API 侧**知识——只有 `add_block` 需要它。模型文件不需要：`.slx` 内部 XML 里普通块只记 `BlockType`，Simulink 载入时自己解析（实测：只写 `BlockType="Gain"`、零库路径的新块能被识别、参数可读回、连线成立、仿真逐信号一致）。

所以：
- XML 原地结构编辑**不需要**块型白名单；
- M 路线与 XML→M 回灌需要，走共享表 `snp_block_source`—— **一条概念一个名字，一份表，不复制第二份**。

## 库改动怎么传播（设计种子）

引用模型的库实例是**链接式**（`ReferenceBlock` / `LinkStatus='resolved'`）：模型快照只记链接 `add_block('mylib/blk',…)`，不记库内部参数。所以**改库 → 自动重建引用它的模型**是成立的（实测：库 Gain 2→7，未改动的模型快照重建后实例自动带新值）。

将来做自动传播只需两步：**重建库 + 重建引用模型**。模型快照无需同步。

## 双向保留（为什么注释不会丢）

`snp_pull` 的合并按**节**对齐 + **块名**对齐：节标题/注释/辅助行（手写区）一律保留旧的；语句（块 X）按模型现状换新。这既是工程实现，也是对"人机协作"的核心承诺：**agent 写的代码结构，人改 GUI 不会弄坏；人改的模型，agent 也不会覆盖**。

与官方工具的分工：
- MathWorks 的 Comparison / Three-Way Merge 做**模型↔模型**比较，产出仍是 `.slx`——agent 读不了也改不了；
- 本项目填的是**模型↔可读代码**的双向层，让 LLM 和人共享同一份文本。
